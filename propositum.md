# Propositum

> Productividad personal organizada desde el propósito hasta la acción.

**Estado:** en desarrollo; migración tecnológica planificada/en curso según el contexto del proyecto.  
**Código:** privado · Producto en evolución.

## Problema

Una lista de tareas puede organizar pendientes sin explicar cómo se relacionan con los roles, objetivos y prioridades de una persona.

## Propuesta

Organizar el trabajo mediante la jerarquía **Propósito → Roles → Objetivos → Metas → Tareas**, para mantener visible la relación entre las acciones diarias y aquello que se busca alcanzar.

## Mi participación

Definición del modelo conceptual, requisitos funcionales, estructura de datos y dirección de la evolución técnica del producto.

## Evolución tecnológica

El proyecto parte de una implementación con Flask y SQLite. Su dirección de evolución contempla Node.js, Express y MySQL.

El enfoque PWA y las opciones de autenticación reforzada forman parte del diseño previsto; esta ficha no los presenta como funciones verificadas ni anuncia una versión pública disponible.

## Qué busca demostrar

- Modelado de relaciones entre propósito, responsabilidades y ejecución.
- Conversión de una necesidad de organización en un modelo de aplicación.
- Evolución tecnológica gradual de un producto.

## Presentación

El alcance y la disponibilidad de una demostración se confirman directamente. Todavía no se publican métricas de adopción o productividad.
